# Codex 双层智能体控制台


一个运行在本机的网页控制台，用于创建和管理 Codex 双层智能体任务。你可以分别选择思考层与执行层的模型和推理强度，也可以使用自定义服务商、Claude Code 或本地 Agent。

> 控制台用于组织任务和调用本机工具，不提供模型 API 服务。任务内容会发送给你所选的模型或服务商。

## 功能

- **双层模型配置**：思考层负责理解目标、规划步骤；执行层负责在项目中执行任务。两层可以使用不同的模型和推理强度。
- **多种运行模式**：支持 Codex GPT、自定义模型、混合模式、Claude Code 和本地 Agent。
- **自定义服务商**：可添加多个 Responses API 服务商，维护各自的模型列表，并分别测试连接、从上游读取模型。
- **任务记录**：查看最近任务、对话、可用的 Token 用量及工具活动摘要。显示内容以本机 Codex App Server 实际提供的数据为准。
- **图片与 Apps**：任务输入可附加图片；符合本机 Codex 版本和授权条件时，可以使用可用的 Apps 连接器。
- **本地项目管理**：为任务选择本机项目目录，任务在所选项目的权限设置下运行。

## 开始使用

1. 从 [GitHub Releases](https://github.com/wdbfl998/cccccx/releases/latest) 下载朋友版压缩包并解压。
2. 在 Windows 上安装 Node.js 和 Codex CLI，并完成 Codex 登录。
3. 双击 `启动控制台.bat`。
4. 按启动窗口显示的地址打开控制台，默认地址为 `http://127.0.0.1:4173`。
5. 添加或选择项目目录，选择运行模式和模型，然后输入任务。

使用期间请保持启动窗口运行。任务涉及命令或文件修改时，按页面中的审批提示进行处理。

## 运行模式

- **GPT 模式**：使用本机 Codex App Server 提供的模型目录和账户状态。
- **自定义模型**：使用已配置的 Responses API 服务商和模型。
- **混合模式**：思考层与执行层可以分别选择 GPT 或已配置的自定义模型。
- **Claude Code**：需要本机已安装并登录 Claude Code CLI；执行仍遵循 CLI 的权限确认。
- **本地 Agent**：可登记或导入本机 Agent 应用。对于没有可调用 CLI/API 的应用，控制台会把任务交给你手动提交。

## 自定义服务商与 API Key

在“服务商配置”页面添加服务商名称、Base URL、模型和 API Key。读取 `/models` 用于获取模型列表；连接测试会实际向上游发送测试请求，可能产生服务商用量。

API Key 不包含在发布压缩包中。默认情况下，直接输入的 Key 只保留在控制台服务进程内存中；勾选“加密保存到本机”后，会使用 Windows DPAPI 按当前 Windows 用户加密保存。也可以使用本机环境变量。

## 本地数据与权限

- 控制台服务默认只监听本机地址 `127.0.0.1`。
- 项目列表保存在本机的 `projects.json`；自定义服务商配置保存在 Codex 用户目录中。
- 选择加密保存时，API Key 以当前 Windows 用户的 DPAPI 密文保存在本机，不会随发布压缩包上传。
- 任务的文件访问、命令权限和审批遵循所选项目及本机 Codex 配置。

请勿将 API Key、个人配置或包含私有项目路径的文件提交到公开仓库。不同模型、服务商和本机 Codex 版本支持的能力可能有所不同。
